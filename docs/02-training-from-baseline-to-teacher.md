# 从基线到教师

## 三阶段演化

训练不是直接从高精度教师起步的，而是走了三步：

1. **工程基线**：验证训练框架、评估流程、导出工具链可靠
2. **精度冲击**：架构升级（自研结构 → EfficientNet-B0 迁移学习）
3. **教师体系**：ensemble + soft target 导出 + 蒸馏基础设施

这一步步走的价值在于：它把"训练结果"从孤立的数字，变成了**可追溯、可导出、可被
学生消费的工程资产**。

## 阶段一：轻量 CNN 基线

自研 `tiny_fashion_cnn`，两层 Conv-BN-ReLU-MaxPool + 全连接头，28×28 灰度输入。

| 配置 | 值 |
|---|---|
| batch_size | 256 |
| epochs | 12 |
| lr / weight_decay | 0.001 / 1e-4 |
| 设备 | Apple MPS |
| 耗时 | ~98.7 秒 |

结果：**最佳验证 92.20%，测试 91.74%**。

一个有用的观察：约 8 轮后精度就基本收敛。这个快速收敛特性后来成为所有轻量
student 训练的轮次参考。

## 阶段二：架构升级

### 尝试过但没走通的路：自研 SE-ResNet

含 Squeeze-Excite 的残差网络，配 label smoothing、EMA、one-cycle 调度和较强数据
增强。精度有提升，但**工件完整性不足**，未成为主教师。

这里的教训不在技术，在工程：一个"精度更高但工件不全"的模型，无法承担教师职责。
教师的核心产出不是 accuracy，是 soft target。

### 走通的路：EfficientNet-B0 迁移学习

切换理由：

1. Fashion-MNIST 灰度图可三通道复制接入 ImageNet 预训练骨干
2. 成熟骨干精度上限更高、训练更稳定
3. "轻量 CNN → 自研结构 → 预训练骨干"的叙事符合工程演化逻辑

关键设计决策：

- 输入 28×28 **上采样至 96×96**，更好利用预训练特征
- 灰度复制为三通道
- EMA 提高 checkpoint 稳定性
- AdamW + cosine + 数据增强（旋转、仿射、random erasing）

## 训练节点汇总

| 实验 | 备注 | 最佳验证 | 测试 |
|---|---|---:|---:|
| `baseline_cnn` | 轻量 CNN，12 轮 | 92.20% | 91.74% |
| `eb0_transfer_95` | EB0 迁移学习 | 95.13% | **94.77%** |
| `eb0_finetune_95` | 低 LR 精修 | 95.20% | 94.55% |
| `eb0_fulltrain_95` | 全量数据定型 | — | 94.63% |
| `eb0_teacher_96_refine` | teacher refine | 95.17% | — |
| `ensemble_besttest` | 双模型 ensemble | 95.32% | 94.88% |
| `ensemble_bestval` | 双模型 ensemble | 95.52% | 94.74% |

## 四条规律

### 1. 迁移学习的跃升效应

从自研轻量 CNN（91.74%）到 EB0 迁移（94.77%）是 **约 3 个百分点**的跃升，远高于
继续优化自研结构的边际收益。

**当自研结构卡住时，换一个成熟骨干往往比继续调参划算。** 这是投入产出比最高的一次
决策。

### 2. 单模型精度边际递减

EB0 到 94.77% 之后，精修（val +0.22%、test **−0.22%**）和续跑都没带来测试集上的
稳定提升。**单模型已进入边际收益递减区。**

注意 val 涨 test 跌这个组合 —— 这是过拟合验证集的典型信号，也是"不要只看 val 选
checkpoint"的直接证据。

### 3. 全量训练不自动带来提升

把全部 60000 张加入训练（val_split=0）后测试 94.63%，**不超过**保留验证集的
94.77%。验证集监控对防止过拟合仍有价值。

直觉上"数据更多应该更好"，但失去监控后的早停点选择变差了，两相抵消。

### 4. Ensemble 的稳健增益

双模型 ensemble 在 test 上 94.88%（比最佳单模型 +0.11%）。提升幅度有限，**但作为
蒸馏知识源时，ensemble 软标签分布更稳定、信息熵更丰富**。

也就是说：ensemble 的直接收益小，间接收益（作为教师）大。评估它时不能用单模型的
尺子。

## 教师建立的工程规范

这几条规范对后续所有路线有基础性保障意义，值得单独强调：

- **非作弊/作弊隔离**：正式实验不将测试集并入训练
  （`train_includes_test_split = false`），保证部署结论不被数据泄漏污染
- **split seed 解耦**：训练/验证划分随机性通过独立 `split_seed` 固定，使 ensemble
  搜索与对比实验公平可比
- **完整工件归档**：每次训练保存 `best_model.pt`、`best_model.onnx`、
  `fpga_test_bundle.npz`、`metrics.json`、`history.csv`

代码里 `train_includes_test_split` 这个开关被写成了**直接抛异常**而不是警告 —— 它
存在的唯一目的是让"非作弊"这个保证可被审查。
